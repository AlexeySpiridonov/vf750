# VF750 Resources

Checked: 2026-04-29

## Main Forums

- [V4 Honda BBS](https://www.v4hondabbs.com) — general V4 Honda forum.
- [V4 Muscle Bike](https://v4musclebike.com/forums/) — main V4 community, includes the 82-86 Magna/Sabre section.
- [V4MuscleBike 1st Gen Magna/Sabre section](https://v4musclebike.com/forums/1st-gen-honda-magna-and-sabre-1982-1986.4/) — primary source for field reports on V30/V42/V45/V65 Magna and Sabre repairs.
- [VFRworld VF750 tag](https://vfrworld.com/tags/vf750/) — VF750-tagged threads on the VFR community forum.
- [VF1000 forum](https://forum.vf1000.com) — VF1000 community with technical V4 discussion.
- [VF750 section on VF1000 forum](https://forum.vf1000.com/c/vf750/12) — dedicated VF750 board, including EFI and swap threads.
- [MotorcycleForum](https://www.motorcycleforum.com) — general motorcycle forum.
- [HondaShadow / Magna](https://www.hondashadow.net) — Honda cruiser forum that also covers the Magna.

V4MuscleBike is often recommended as the main resource for practical VF750/Sabre/Magna discussion.

See also: [local V4MuscleBike forum field notes](HowTo/v4musclebike-forum-field-notes.md).

## YouTube References

### Useful VF750 / V45 Sabre / Magna videos

- [Honda VF750 Magna Carb Clean - TheMotorcycleMD](https://www.youtube.com/watch?v=52k8LaD3q4Y) — detailed carb teardown and cleaning; the most practical carb service video found in this pass.
- [Syncing The Carburetors On The Honda VF750 - Revive 2 Ride](https://www.youtube.com/watch?v=EXc9i7zoA9g) — good real-world carb synchronization example on a VF750 project bike.
- [HONDA V45 MAGNA / VF750C / RC09 1982 Carb sync / reglage - ichikonti](https://www.youtube.com/watch?v=3buvmQb6Ogs) — short but useful video specifically for the early VF750C / V45 Magna.
- [Honda V45 Magna Carb Sync Tool - HighTechLab](https://www.youtube.com/watch?v=D0zCyCsNFt4) — DIY carb sync tool reference.
- [1982 Magna V45 Final work: Carbs install, valve clearance and Synch! - Moto-Resto Machine and Repair](https://www.youtube.com/watch?v=BsNvGBBtUAc) — combined reference for carb install, valve check, and final carb sync.
- [Honda VFR750 vs VF750 valve adjustment wisdom and a visit from the DUMB VIDEO POLICE! Watch and see! - Moto-Resto Machine and Repair](https://www.youtube.com/watch?v=dRjBuBrFGhM) — more useful as a discussion of valve train, cam, and oiling concerns than as a step-by-step how-to.
- [Honda Magna V45 Cafe Racer Style - ICCustomsUSA](https://www.youtube.com/watch?v=UlwVQwkROtU) — good visual cafe racer reference using the Magna/Sabre family.
- [NEW 1983 HONDA MAGNA V45 CAFE RACER PROJECT - AvidTV](https://www.youtube.com/watch?v=9gkjgG-AY7E) — short project overview, useful mostly as a visual direction reference.
- [Honda VF750 Cafe Racer by Lucky Customs - NakedBikesNation](https://www.youtube.com/watch?v=qPZOBHhdTv8) — more inspiration than technical documentation, but still useful as a visual reference.

### YouTube summary

- Best-covered topics: carbs, synchronization, basic maintenance, and visual customs.
- Weakly covered topics: complete EFI / ECU swap specifically for the VF750.
- For EFI swap research, forum threads are currently more useful than YouTube.
