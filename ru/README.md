# Проект Honda Sabre 1982 Cafe Racer

Английский оригинал: `README.md`

Этот репозиторий — техническая база для переделки `1982 Honda VF750S Sabre` в `cafe racer`.

Здесь собраны сервисные мануалы, каталоги деталей, исследовательские заметки, фото-референсы и практические инструкции по проекту.

## Цель проекта

- Подробно разобраться в штатной платформе V45 Sabre.
- Подготовить сервисную документацию в поисковом и структурированном виде.
- Исследовать ключевые зоны переделки: передняя подвеска, EFI, электрика и общий cafe-racer дизайн.
- Спланировать визуальную и техническую конверсию мотоцикла.

## Быстрый старт

Если начинаешь работу с репозиторием, иди в таком порядке:

1. Прочитай `README.md`, чтобы понять структуру репозитория.
2. Открой `HowTo/README.md` для основных работ по обслуживанию, диагностике и модификациям.
3. Посмотри `problems.md` — там собраны типовые слабые места VF750 / V45.
4. Для проводки и зарядки сначала используй `Manuals/electrical-reference/`.
5. Для блоков зажигания / CDI / TCI, углов зажигания и диагностики используй `manuals/cdi-reference/`.
6. Для карбюраторов (выдержки из мануалов, каталог деталей, заметки по неисправностям) используй `Manuals/carburetor-reference/`.
7. Для передней подвески и свапа вилки смотри `Tuning/fork swap.md`.
8. Для EFI / ECU конверсии смотри `Tuning/ecu swap.md`.
9. Для дизайна и реальных тем сборки смотри `Tuning/sabre-cafe-racer-projects.md` и `Images/`.
10. Для форумов, внешних источников и каталогов деталей смотри `resources.md`.

### Обработанные материалы

PDF-файлы в `Manuals/` были превращены в PDF с поиском и OCR-слоем, затем разбиты по разделам:

- **Мануал Haynes** — 10 разделов: от вводной части до электрики и таблиц пересчета.
- **Каталог деталей** — 5 разделов: вводные страницы, двигатель, рама, индекс номеров деталей и индекс описаний.
- **Справочник по электрике** — единый пакет по системе зажигания, электросистеме, схемам проводки, каталогу электрических деталей и типовым неисправностям.
- **Справочник по CDI** — отдельный пакет по блокам зажигания / TCI, контрольным точкам зажигания, диагностике и вариантам замены.
- **Справочник по карбюраторам** — сборный пакет: выдержки по карбюраторам из Haynes и заводского мануала, страницы каталога деталей и заметки по процедурам, типовым проблемам и видео.

Каждый сгенерированный пакет содержит `manifest.json` с привязкой к исходникам и диапазонами страниц.

### Скрипты обработки

- `.scripts/process_haynes_manual.py` — OCR и разбиение мануала Haynes.
- `.scripts/process_partslist.py` — OCR и разбиение каталога деталей.
- `.scripts/build_electrical_reference.py` — сборка пакета по электрике.
- `.scripts/build_carburetor_reference.py` — сборка пакета по карбюраторам.

## Практические инструкции

- `HowTo/README.md` разбивает работы по задачам: регулировка клапанов, инспекция распредвалов, мод подачи масла к головам, снятие и установка карбюраторов, поиск проблем с подачей топлива, чистка и синхронизация карбов, зарядка, охлаждение, сцепление, подвеска, кардан, тормоза, тюнинг и изготовление деталей для cafe racer.
- `problems.md` сводит основные повторяющиеся проблемы VF750: износ распредвалов, смазка верхней части двигателя, натяжители цепей ГРМ, зарядка, карбюраторы, CDI/TCI, Pro-Link и связанные диагностические цепочки.
- `HowTo/v4musclebike-forum-field-notes.md` превращает индекс форума V4MuscleBike 1st Gen Magna/Sabre в карту типовых тем, исходных веток и подходящих локальных статей.
- `Tuning/top-end-oiling.md` разворачивает тему смазки головок цилиндров в отдельную практическую заметку: базовые проверки, внешний подвод масла и ограничения популярного мода.
