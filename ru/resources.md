# Ресурсы VF750

Английский оригинал: `resources.md`

Проверено: 2026-04-29

## Основные форумы

- [V4 Honda BBS](https://www.v4hondabbs.com) — общий форум по Honda V4.
- [V4 Muscle Bike](https://v4musclebike.com/forums/) — главное V4-сообщество, есть раздел Magna/Sabre 82-86.
- [V4MuscleBike 1st Gen Magna/Sabre](https://v4musclebike.com/forums/1st-gen-honda-magna-and-sabre-1982-1986.4/) — основной источник полевых отчетов по ремонту V30/V42/V45/V65 Magna и Sabre.
- [VFRworld VF750 tag](https://vfrworld.com/tags/vf750/) — темы с тегом VF750 на форуме VFR-сообщества.
- [VF1000 forum](https://forum.vf1000.com) — сообщество VF1000 с технической V4-дискуссией.
- [VF750 section on VF1000 forum](https://forum.vf1000.com/c/vf750/12) — отдельный раздел по VF750, включая EFI и свапы.
- [MotorcycleForum](https://www.motorcycleforum.com) — общий мотофорум.
- [HondaShadow / Magna](https://www.hondashadow.net) — форум по круизерам Honda, затрагивает и Magna.

V4MuscleBike часто оказывается самым полезным ресурсом для практических вопросов по VF750/Sabre/Magna.

См. также: [локальные заметки по форуму V4MuscleBike](HowTo/v4musclebike-forum-field-notes.md).

## YouTube

### Полезные видео по VF750 / V45 Sabre / Magna

- [Honda VF750 Magna Carb Clean - TheMotorcycleMD](https://www.youtube.com/watch?v=52k8LaD3q4Y) — подробная разборка и чистка карбюраторов; самое практичное видео по обслуживанию карбов из найденных.
- [Syncing The Carburetors On The Honda VF750 - Revive 2 Ride](https://www.youtube.com/watch?v=EXc9i7zoA9g) — практический пример синхронизации карбюраторов на проектном VF750.
- [HONDA V45 MAGNA / VF750C / RC09 1982 Carb sync - ichikonti](https://www.youtube.com/watch?v=3buvmQb6Ogs) — короткое, но полезное видео именно по раннему VF750C / V45 Magna.
- [Honda V45 Magna Carb Sync Tool - HighTechLab](https://www.youtube.com/watch?v=D0zCyCsNFt4) — референс по самодельному инструменту для синхронизации.
- [1982 Magna V45 Final work - Moto-Resto Machine and Repair](https://www.youtube.com/watch?v=BsNvGBBtUAc) — установка карбов, регулировка клапанов и финальная синхронизация в одном видео.
- [Honda VFR750 vs VF750 valve adjustment wisdom - Moto-Resto Machine and Repair](https://www.youtube.com/watch?v=dRjBuBrFGhM) — полезно скорее как обсуждение клапанного механизма, распредвалов и смазки, чем как пошаговая инструкция.
- [Honda Magna V45 Cafe Racer Style - ICCustomsUSA](https://www.youtube.com/watch?v=UlwVQwkROtU) — хороший визуальный cafe-racer референс на базе семейства Magna/Sabre.
- [NEW 1983 HONDA MAGNA V45 CAFE RACER PROJECT - AvidTV](https://www.youtube.com/watch?v=9gkjgG-AY7E) — короткий обзор проекта, полезен в основном как визуальное направление.
- [Honda VF750 Cafe Racer by Lucky Customs - NakedBikesNation](https://www.youtube.com/watch?v=qPZOBHhdTv8) — скорее вдохновение, чем техническая документация, но полезно как визуальный референс.

### Вывод по YouTube

- Лучше всего покрыты карбы, синхронизация, базовое обслуживание и визуальные кастомы.
- Слабее всего покрыта полная EFI / ECU конверсия именно для VF750.
- Для исследования EFI сейчас полезнее форумы, чем YouTube.
